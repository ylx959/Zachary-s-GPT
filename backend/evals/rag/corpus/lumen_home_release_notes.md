# Lumen Home App — Release Notes

Release notes for the Lumen Home app on iOS and Android. Versions are listed newest first.

## Version 5.4.0

- Added room-by-room cleaning order for the Atlas X2 Pro: drag rooms in the map to choose the order.
- Added a "pet mode" for the Atlas X2 Pro that increases suction around feeding areas and avoids pet bowls more widely.
- The cleaning history now shows a heat map of the areas cleaned in each run.
- Fixed a bug where schedules set in a different time zone started one hour late after a daylight saving change.
- Minimum supported versions are now iOS 16 and Android 10.

## Version 5.3.2

- Fixed a crash when opening the map of a home with more than 12 rooms.
- Fixed push notifications not arriving on some Android 14 devices with battery optimisation enabled.
- Improved pairing reliability for the Atlas X1 on mesh Wi-Fi networks.

## Version 5.3.0

- Added support for the Atlas X3 Mini, including its simple map and virtual walls.
- Added a "Do not disturb" period: robots will not start scheduled runs during this time, and voice prompts are muted.
- Consumables tracking now reminds you to replace filters and brushes based on actual running hours instead of fixed dates.
- Added Traditional Chinese and Japanese translations.

## Version 5.2.0

- The app can now share a home with up to 6 family members. Shared members can start and stop cleaning but cannot delete maps.
- Added two-factor authentication for Lumen accounts using an authenticator app.
- Cleaning reports can be exported as CSV from the history screen.
- Removed support for the discontinued Atlas X0 robot.

## Version 5.1.1

- Fixed the battery percentage showing 0% while the robot was charging on some X2 Pro units.
- Fixed a rare issue where no-go zones moved slightly after a map was rotated.

## Version 5.1.0

- Added voice assistant integrations: robots can now be started and stopped by voice through supported smart speakers.
- Added a widget for the home screen showing the robot status and a start button.
- Map editing: rooms can now be split and merged manually.

## Version 5.0.0

- New design with a dark mode that follows the system setting.
- The map is now rendered in 3D for robots with LiDAR navigation.
- Firmware updates for the X2 Pro are now offered in the app instead of being installed silently.
- Accounts created with a phone number only must add an email address before September 30 to keep access.

## Known issues

- On some Android tablets in landscape mode, the map editor buttons overlap. Rotate the device to portrait as a workaround.
- The heat map in the cleaning history is not available for robots without mapping, such as the Atlas X1.
